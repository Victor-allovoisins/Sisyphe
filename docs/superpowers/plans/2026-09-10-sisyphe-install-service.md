# Sisyphe install & service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** installer Sisyphe sur macOS ou Ubuntu en un clone et un script, puis piloter le daemon comme un service utilisateur (launchd, systemd) depuis la CLI et l'interface.

**Architecture:** un module `src/service/` expose `ServiceManager` (`status`, `install`, `start`, `stop`, `uninstall`) avec trois implémentations (launchd, systemd, none) choisies par plateforme et un `exec` injectable ; `setup`, `doctor`, `service` et l'UI passent par lui ; `sisyphe ui` crée et migre la base si besoin ; `install.sh` installe les prérequis et compile. Spec : `docs/superpowers/specs/2026-09-10-sisyphe-install-service-design.md`.

**Tech Stack:** Node 24+, TypeScript strict ESM, execa, vitest, POSIX `sh`. Aucune dépendance ajoutée.

Ce plan décrit des contrats et des tests, pas du code verbatim. Chaque tâche finit par `npm test`, `npx tsc --noEmit` et un commit. À réaliser après les tâches 2 et 3 du plan `2026-09-09-sisyphe-ui-actions.md` (le `ControlClient` est utilisé pour l'arrêt propre) et avant sa tâche 4.
